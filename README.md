# FPV Місія

FPV-симулятор з двома режимами: **одиночна місія** і **онлайн кооператив** (кімнати з кодом, синхронізація раз на секунду).
Знищуй танки й вантажівки, збивай Shahed, уникай ППО. Підтримує геймпад, USB-пульт (Radiomaster GX12 та ін.), клавіатуру й екранні стіки на телефоні.

## Що всередині

```
index.html     уся гра (three.js підтягується з CDN)
api/room.js    серверна функція для онлайну (кімнати, пілоти, знищені цілі)
package.json
```

Одиночна місія працює без сервера. Онлайну потрібне сховище Redis.

## Як розгорнути на Vercel

1. Залий папку в GitHub-репозиторій (або запусти `vercel` з цієї папки).
2. Імпортуй проєкт у Vercel. Framework preset: **Other**. Налаштування збірки не потрібні.
3. У проєкті відкрий **Storage** (або Marketplace) і додай **Upstash Redis** (є безкоштовний план).
   Vercel сам додасть змінні `KV_REST_API_URL` і `KV_REST_API_TOKEN`
   (або `UPSTASH_REDIS_REST_URL` і `UPSTASH_REDIS_REST_TOKEN`). Функція розуміє обидва варіанти.
4. Зроби **Redeploy**, щоб змінні потрапили в функцію.
5. Відкрий сайт, вибери «Онлайн кооператив», натисни «Створити» і передай код другу.

Локально: `npx vercel dev` (підтягне змінні командою `vercel env pull`).

## Як працює онлайн

- Кімната зберігається в Redis: час старту, зерно (за ним усі пілоти бачать однакові Shahed), список знищених цілей і позиції пілотів.
- Кожен клієнт раз на секунду надсилає свою позицію й нові знищення та отримує стан кімнати. Інші пілоти показуються блакитними «привидами» з екстраполяцією руху.
- ППО й обстріл рахуються локально для кожного пілота, тому затримка мережі на них не впливає.
- Кімната до 6 пілотів. Якщо 60 секунд нікого немає, наступний вхід починає чисту місію. Кімната зникає з Redis через 2 години без активності.

## Керування

| Дія | Геймпад / пульт | Клавіатура |
|---|---|---|
| Газ, рискання | ліва вісь | W S, A D |
| Тангаж, крен | права вісь | стрілки |
| Нова спроба / нова місія | A | R |
| Режим Acro / Angle | X | M |
| Вид FPV / ззаду | Y | V |
| Меню | Start | Esc |

Налаштування осей, пресет Radiomaster GX12 і тумблер Arm є в меню (Esc).
